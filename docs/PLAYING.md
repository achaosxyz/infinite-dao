# 游玩指南

## 启动与退出

在项目根目录双击 `启动游戏.cmd`，打开 Godot 原生游戏窗口。它沿用工作区的配置和存档；无需保持浏览器或后台服务。源码开发也可以运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/start-game.ps1
```

直接关闭游戏窗口即可退出，重新打开后可在标题页读取自动存档。独立便携版位于 `artifacts/releases/InfiniteDao-Godot-Windows/`，运行 `InfiniteDao.exe`。它不监听任何本地游戏服务端口；智能世界才会按需向配置的模型服务发送请求。

## 第一次接掌宗门

1. 选择六宗之一。头像、天赋、起始领地和初始修士各不相同。
2. 选择世界模式、难度和种子。智能世界使用本地配置的模型；离线世界不调用 API，两种模式都有完整胜利与重建闭环。
3. 首次议事决定开局加成。建议初学者先富山门或执剑开疆。
4. 开宗选择后默认自动演进。宗门页只选战略，门徒页可重点培养和配护道人，其余日常由执事和门人自行处理。

## 定战略，看流年

- **战略**：选择均衡、休养、修炼、扩张或外交；执事依方向自动招募、营建、传功、疗伤和筹备战争。
- **查看**：点地图地域看人口、矿藏、护阵与邻接，滚轮缩放、右键拖图；点人物看潜力、修为、伤势与生平。
- **门人**：可重点培养至多三人，额外消耗灵材以加快修为；突破仍需修龄。为弟子选更高境界的护道人，实际随行降低历练危险，并非保证免死。
- **推进**：默认自动运行；“推演一载”逐月推进最多一年，遇议事即停。空格随时暂停，切换资料页不停止时间；窗口失焦和待决议事会暂停。网络请求发出后，暂停停止后续月份，不撤回本次可能计费请求。

历练持续一至三年，门人和护道人不能同时参加另一场历练或战争。高阶修士受托护道会占用战斗人手。伤势、寿尽、战死和历练陨落均记入人物小传与史书；门徒页可勾选故去门人。重点培养不等于无敌。

丹材不足时，执事会以盈余灵石自动向坊市采办，4灵石换1丹材；不会花掉半年供养底线。开疆/均衡策略先攒军需，再分配修炼。若供养过重，选择休养生息积累财富，不必逐人点补给。

## 征战与外交

执事只选择接壤地域，备足动员与长期军需后才出征。无主地至少一年，宗门守地通常数年；每月耗补给，断粮撤军。七成可调动门人远征，余者留守。在外历练者不能重复部署。受到入侵会请掌门选择防守或保存薪火。

结算逐人交锋：金丹打元婴的境界倍率为0.12，低两境再乘0.12；高境修士不是一堆低境战力的简单等价物。护山阵、军阵、法宝、情报、战疲、战术和供给共同影响实战。军情窗口可查看参战人数、逐人伤害与伤亡。外交策略自动经营五年盟约，盟约内不攻击；终局仍需灭掉其他五宗道统。

## 灭门后继续

最后一块领地失守会触发“山门虽毁，道统未绝”，最多六名幸存门徒带走道藏、军阵、法宝和紧急余资。选择薪火去向后，在地图或重建列表选择落脚点：

- 无主地：支付150灵石。
- 天下没有无主地时，可在他宗非山门领地支付350灵石赎地。

宗门名字、人物身份、年份和历史延续；原有其他宗门仍在，不重置地图。这条机制不是失败惩罚页，而是同一场战役的下一章。

## 智能世界与费用

密钥放在 `config/llm.local.json`，不要发到聊天或打入资源。当前使用Anthropic Messages，`request.thinkingMode=adaptive`、`request.reasoningEffort=high`。各敌宗保存公开会话与长期计划，仅在首次规划、重大变化或复盘时进入后台工具循环；平静月份不请求模型。默认最多10个Agent同时运行，时间不会等待模型，期间继续执行原战略；返回计划会重新校验目标。议事先显示规则选项，后台叙事不会改变费用与效果。计划、议事、compact均走原生严格工具提交。

每宗上下文上限256000 tokens，输入加预留输出达到230400时 compact。摘要与原公开归档随存档保存，不保存隐藏思考。可在“诸宗外交 → 议政计划与记忆”查看计划、复盘时间、输入计数与公开会话节选。模型生成请求与上下文计数HTTP分开统计；单次唤醒默认最多8轮，只重试失败任务，不重发已完成的其他宗门。

调用没有总次数上限，只控制并发，可能持续计费。调用失败后按1/2/4秒退避自动重试3次（加上初次最多4轮）；仍失败则显示提示、记入史书并切换离线规则，时间继续流逝。检查配置后可在设置中手动恢复智能世界，不会自行重新联网。超时与重试也可能计费。设置显示实际次数与token数，不展示或保存隐藏思考。

## 存档

每次成功操作自动保存。按 Ctrl+S 或点击“宗门存档”，可写三个手动位置、恢复旧分支或导出 JSON。导入与导出使用系统文件选择器；明确选择导入文件会替换当前世界，建议先保存当前分支。导入失败不会破坏当前世界。

开发运行的存档位于 `artifacts/game/saves/`，不进入版本控制。Windows 便携版使用它自己目录内的 `artifacts/game/saves/`；两个运行目录的存档彼此独立，可用导入导出搬迁。

## 快捷键与显示

- 空格：演进 / 暂停。
- Esc：关闭资料窗口；无窗口时暂停。
- Ctrl+S：打开存档。
- Tab、Enter：键盘导航和确认；地图获得焦点后可用方向键选地、Enter 查看。
- 鼠标滚轮 / 右键拖动：地图缩放与平移；“复位地图”恢复全图。

推荐 1440 × 900 桌面窗口，可调整大小。中文界面使用 Windows 系统字体，不依赖远程字体；图片与所有交互均由 Godot 原生渲染。
