# 游玩指南

## 启动与退出

在项目根目录双击 `启动游戏.cmd`，打开 Godot 原生游戏窗口。它沿用工作区的配置和存档；无需保持浏览器或后台服务。源码开发也可以运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/start-game.ps1
```

直接关闭游戏窗口即可退出，重新打开后可在标题页读取自动存档。独立便携版位于 `artifacts/releases/InfiniteDao-Godot-Windows/`，运行 `InfiniteDao.exe`。它不监听任何本地游戏服务端口；智能世界才会按需向配置的模型服务发送请求。

## 第一次接掌宗门

1. 选择十宗之一：青云、赤霞、百草、天工、镜水、玄霜、雷霆、金禅、星罗、幽篁。宗徽、天赋、山门和初始修士各不相同。
2. 选择世界模式、难度和种子。智能世界使用本地配置的模型；离线世界不调用 API，两种模式都有完整胜利与重建闭环。
3. 首次议事决定开局加成。建议初学者先富山门或执剑开疆。
4. 开宗选择后默认自动演进。宗门页只选战略，门徒页可重点培养和配护道人，其余日常由执事和门人自行处理。

## 定战略，看流年

- **战略**：选择均衡、休养、修炼、扩张或外交；执事依方向自动招募、营建、传功、疗伤和筹备战争。
- **查看**：点地图地域看人口、矿藏、护阵与邻接，滚轮缩放、右键拖图；点人物看潜力、修为、伤势与生平。
- **门人**：先看特性再决定重点培养，最多选三人。凡体、通灵之体、异灵根、天灵根、先天道体有明显培速/实战差距，上限依次为金丹、元婴、化神、合体、大乘，不能靠反复培养洗掉先天差异。名册优先显示重点人物、掌门和高特性门人。护道人实际同行，但不保证免死。
- **推进**：一回合一个月，只有地图自动演进；切到宗门、门徒、外交、道藏、史书等页或打开详情会自动暂停，正在提交的当前月安全结束后停止，培养和调配不再被连续月结抢占。返回地图仍暂停，按继续/空格才恢复；在资料页点继续会先返回地图。“推演一载”遇议事即停；失焦也暂停。暂停不撤回已发出的可能计费模型请求。

历练持续一至三年，门人和护道人不能同时参加另一场历练或战争。高阶修士受托护道会占用战斗人手。伤势、寿尽、战死和历练陨落均记入人物小传与史书；门徒页可勾选故去门人。重点培养不等于无敌。

门人归山可寻得随身法宝，执事会优先使用已有库存、自动补位并将同类旧物换成可御使的更高阶器物，换下的旧物继续传给其他门人。御敌法宝提高持有人自己的战斗伤害；护身法宝降低本人历练风险，但不保证生还。你无需操作法宝也能自然获得和传承。重点人物小传中可选赐予并保留所选物品；改选“交给执事”恢复自动安排，在外时等归山后才会换新。故去人物的经历区分当时去向与如今下落。

人物从50张共享立绘中选图并随存档固定，优先使用当前在世门人占用较少的图；世界人数可以超过50。继任掌门保留自己的立绘，先辈记录保留原图。本版只接受Schema4新档，旧文件不会被修改，但需要新开局。

化神之后还有分神、合体、大乘。寿元依境界为28/36/48/62/78/94/110/130年，让几百个月回合里能见到成长与更替。大乘满九年会有一次飞升之议，满十年默认飞升；底蕴+1，全宗生产/修炼+5%（总加成上限50%），随身法宝留宗并自动传承。若人物值得硬留，可在议事或详情开启留世：申请不收费，到期后每月至少3000灵石/800灵材，并逐年加价；保不住供养/军需时自动飞升，且留世不延寿。NPC默认自动飞升，无须玩家逐人处理。

高阶门人满修为后仍支付灵石与灵材常例供养，另有实际修炼、重点培养、突破、军需和留世费用。缺供时先停培养，不会耗材却零成长。执事按4灵石换1灵材自动采办，保留供养/军需，并先为即将破境的重点或高特性人物备资，再考虑建设和普通晋阶。道藏、军阵高等级更昂贵；不必逐人点补给。

常规议事的资源费用与收益按本宗产出增长，不再一直是开局小额；封顶的付费提升和明显无收益的庆典会减少，天才拜山可能直接带来高特性亲传。直接看规则、成本与收益决定，不需要等待模型写描述。

## 征战与外交

执事只选择接壤地域，备足动员和军需后出征。无主地基础2+护阵月、有主地6+2×护阵月，险地和距离另计；逐月耗补给、断粮撤军。七成可调动门人远征，余者留守，在外历练者不重复部署。攻方战疲每月+1，护阵每级增伤8%，燃灵护山费用随宗门供养增长；不再靠几十个月围攻单方面叠满攻方疲劳。

结算逐人交锋：金丹打元婴的境界倍率为0.12，低两境再乘0.12；高境修士不是一堆低境战力的简单等价物。护山阵、军阵、法宝、情报、战疲、战术和供给共同影响实战。军情窗口可查看参战人数、逐人伤害与伤亡。外交策略自动经营五年盟约，盟约内不攻击；终局仍需灭掉其余宗门道统，十宗新局有九个对手。

高境修士以低境敌人为首目标时，一轮最多攻击四名不同低境敌人；同境或更高境目标仍是单次攻击，低境方仍能同轮反击。普通条件下一个元婴可以战胜十名金丹，但重伤、强阵或补给与战疲劣势仍可能翻盘。展示总战力只是参考，执事会按实际可出战阵容与境界对局判断是否出征，而不是看到总战力较低就一律放弃。

## 灭门后继续

最后一块领地失守会触发“山门虽毁，道统未绝”，最多六名幸存门徒带走道藏、军阵、法宝和紧急余资。选择薪火去向后，在地图或重建列表选择落脚点：

- 无主地：支付150灵石。
- 天下没有无主地时，可在他宗非山门领地支付350灵石赎地。

宗门名字、人物身份、年份和历史延续；原有其他宗门仍在，不重置地图。这条机制不是失败惩罚页，而是同一场战役的下一章。

## 智能世界与费用

密钥放在 `config/llm.local.json`，不要发到聊天或打入资源。当前使用Anthropic Messages，`request.thinkingMode=adaptive`、`request.reasoningEffort=high`。各敌宗保存公开会话与长期计划，仅在首次规划、重大变化或复盘时进入后台工具循环；平静月份不请求模型。默认最多10个Agent同时运行，时间不会等待模型，期间继续执行原战略；返回计划会重新校验目标。议事直接显示规则场景、选项、费用和效果，不额外请求模型扩写描述。计划与compact走原生严格工具提交。

每宗上下文上限256000 tokens，输入加预留输出达到230400时 compact。摘要与原公开归档随存档保存，不保存隐藏思考。可在“诸宗外交 → 议政计划与记忆”查看计划、复盘时间、输入计数与公开会话节选。模型生成请求与上下文计数HTTP分开统计；单次唤醒默认最多8轮，只重试失败任务，不重发已完成的其他宗门。

调用没有总次数上限，只控制并发，可能持续计费。调用失败后按1/2/4秒退避自动重试3次（加上初次最多4轮）；仍失败则显示提示、记入史书并切换离线规则，时间继续流逝。检查配置后可在设置中手动恢复智能世界，不会自行重新联网。超时与重试也可能计费。设置显示实际次数与token数，不展示或保存隐藏思考。

## 存档

每次成功操作自动保存。按 Ctrl+S 或点击“宗门存档”，可写三个手动位置、恢复旧分支或导出 JSON。导入与导出使用系统文件选择器；明确选择导入文件会替换当前世界，建议先保存当前分支。导入失败不会破坏当前世界。

开发运行的存档位于 `artifacts/game/saves/`，不进入版本控制。Windows 便携版使用它自己目录内的 `artifacts/game/saves/`；两个运行目录的存档彼此独立，可用导入导出搬迁。

## 快捷键与显示

- 空格：演进 / 暂停。
- Esc：关闭资料窗口；无窗口时暂停。
- Ctrl+S：打开存档。
- Tab、Enter：键盘导航和确认；地图获得焦点后可用方向键选地、Enter 查看。
- 鼠标滚轮 / 右键拖动：地图缩放与平移；“复位地图”恢复全图。

推荐 1440 × 900 桌面窗口，可调整大小。中文界面使用 Windows 系统字体，不依赖远程字体；图片与所有交互均由 Godot 原生渲染。
