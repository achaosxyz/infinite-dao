# 宗门纪原生美术

- `qinglan-world.png`：1855 × 848，已生成的青绿山河图，用于标题与实时地域地图。
- `sect-leaders.png`：1536 × 1024，已生成的六掌门立绘。按 3 列 × 2 行、每格 512 × 512 作为 Godot AtlasTexture 使用。
- `icon.svg`：山形与月的宗门印记，用于原生窗口标识。

延续既定矿物青绿、深靛、暖铜金视觉。地图上建筑只作背景，地域、归属、选择和阵法标记由实时世界数据绘制，不把背景画作不可变世界事实。

此目录是原生客户端实际使用的资源，不依赖网页、CDN 或个人临时目录。中文字体由 Windows 的楷体、微软雅黑系统字体提供；未复制或分发 Windows 字体文件。模块契约见 [Game MODULE.md](../../../docs/design/GAME/MODULE.md)。
